## 1 · 硅谷 · Kevin

2032 年 1 月 17 日 / Mountain View / NextStream AI 公司办公室。

Kevin O'Brien 23 岁——哈佛 CS 毕业 18 个月——加入 NextStream（B 轮 / 60 人 / 估值 $400M / 做企业级 AI 工作流）做工程师 12 个月——他的工位旁边是 Vikram Patel——28 岁印度裔——Stanford ML PhD——NextStream 资深机器学习工程师——也是 Kevin 的非正式技术导师。

那天早上 9:42——Vikram 给 Kevin 发了一条 Slack——

> "K—coffee?"

Kevin 知道 Vikram 一般不在工作时间约咖啡——他放下手头的 PR review——下楼。

Cafe Verve / Castro Street。

Vikram 把一张纸推过来——USCIS 红头信件——5 行 paragraph。

> "Your H-1B renewal application has been denied under the provisions of Executive Order 2031-12 (Critical Industries Foreign Workforce Restriction). You have 90 days from the date of this notice to depart the United States or adjust to a non-restricted visa status."

Kevin 看了 3 遍。

他抬头看 Vikram——Vikram 平静——他大概昨天就收到了——他大概一夜没睡——但他现在平静。

Kevin："EO-31-12——这是哪个？"

Vikram："R 总统去年 11 月签的——AI / quantum / synthetic biology / advanced materials——四个领域 H-1B 砍 70%——优先驱逐外籍研究员——Stanford 我们这一届 9 个 PhD——已经走了 4 个——剩下 5 个——3 个被拒——包括我。"

Kevin："那你——"

Vikram："我回班加罗尔——那边一个 startup 给我 CTO offer——我太太说她跟我走——她在 Genentech 做研究——她也是绿卡 pending 7 年——再等下去也是被驱逐——我们一起走。"

Kevin："操。"

Vikram 笑了一下：

"K—听我说几句——这不是你们的错——你们不要替我难过——我在美国 9 年——我感谢这个国家——它给我读 PhD / 给我工作 / 给我太太相遇 / 给我一个孩子在 Palo Alto 出生——这些我都记得——但这个国家现在不要我们了——我懂——我走——我不恨——但你们也别假装这没发生——它发生了——这种 R 总统的政策不是抽象的——它是我和我太太收拾家具+我女儿换学校+我这 9 年的美国梦结束——这是真实的——你们不要忘记。"

Kevin 喝咖啡——咖啡苦——他没说话。

---

接下来 90 天 / Kevin 帮 Vikram:

- 1 月底:卖家具 / 退租 (Vikram Mountain View 的房子 / 4 千刀月租 / 退租走 / Kevin 帮搬)
- 2 月:文档移交 / Vikram 把他在 NextStream 的所有项目代码 / 模型权重 / 训练数据 pipeline 都传给 Kevin
- 3 月初:送行 SFO / Vikram 太太抱着 4 岁女儿 / Kevin 和办公室另外两个工程师 / 一起送
- Vikram 临走说:"K—活着比对错重要—你也活下去"
- Vikram 走过安检——回头挥手——消失。

Kevin 开车回 Mountain View——他在 280 高速上哭了 5 分钟——然后他擦干——继续开。

---

3 月 15 日 / NextStream 办公室 / CEO 找 Kevin。

CEO Jason Wei (39 岁 / 华裔美国人 / 自己也焦虑—他的绿卡是 5 年前批的—但他妻子是俄裔—也开始有麻烦):

"K—Vikram 走了 / 你接他的 ML pipeline ownership / 工资我加 25K—但项目不能慢—下季度我们要交付企业版 v2.0—投资人在看。"

Kevin:"懂—我接。"

Jason:"你帮我看 ML 工程师招聘—我们要补 2 个 senior—HR 已经发出去了。"

Kevin 接 HR 给的简历——5 个面试者——他面了 3 周——

第一个: Michigan State 硕士 / 2 年工作经验 / NLP 基础 / 但完全不懂 modern transformer 调优 / 没有产品级 ML pipeline 经验
第二个: 自学转行的全栈工程师 / 看过几个 Coursera 课 / 做过 toy projects / 离 production 距离 12 个月以上
第三个: UCLA PhD candidate / dropping out 找工作 / 做的是 computer vision / 不熟悉 NextStream 用的 LLM stack
第四个: 退伍军人 + 6 个月 bootcamp / 有热情 / 但 ML 基础几乎没有
第五个: Berkeley undergrad / 大四 / 强 / 但他要等到 6 月毕业

Kevin 看完—合上 laptop—他懂了—

**这 5 个人加起来不够 1 个 Vikram。**

不是因为美国本土工程师不努力—是因为美国本土能做到 Vikram 这个水平的人不到 1000 个—他们都已经在 Google / OpenAI / Anthropic / Meta 工作 / NextStream 这种 B 轮 startup 给的薪水（200K base / 0.1% equity）招不到他们——而 H-1B 体系本来是用来填这个缺口的—Stanford / MIT / CMU / Berkeley 出来的外籍 PhD —— 价格合理 / 水平接近 / 愿意来 startup —— 现在被 EO-31-12 砍了 70%。

Kevin 给 Jason 发 Slack:

> "Jason—5 个人面完—没有一个能接 Vikram 的位置。3 号那个 UCLA PhD 是最强的—但他做 vision—我们要 LLM ops—他需要 6-9 个月学 stack—我们没有 6-9 个月。"

Jason 5 分钟后回:

> "Cooper—我懂—想想办法—也许我们重新分配 / 也许 v2.0 砍 features—下午来我办公室聊。"

Kevin 把 laptop 合上——他坐在椅子上——盯着窗外 5 分钟。

他想:

4 年前 R 总统竞选连任——Kevin 19 岁——他在哈佛投了 R 总统——他相信"美国优先"——他相信"我们要恢复制造业"—他看 Tom 那种钢铁工的纪录片觉得"对—我们应该让美国工人有工作"——他从来没想过 EO-31-12 这种政策会直接砍他自己的同事——他从来没把 Vikram 和"H-1B 改革"挂钩—他以为 H-1B 改革是关于"低端职位被占"—不是关于"我每天和我一起 code 的朋友"。

现在他懂了。

但他不能说。

NextStream 拿了一些国防部小合同（DARPA SBIR Phase II / $1.5M）——任何"亲外籍"的姿态会被 OPM 盯上——startup 不能承担这种风险——Kevin 不能写 Substack / 不能发 Twitter / 不能在公司内部说——他只能想——只能在凌晨开车回家时想——只能在床上睡前想。

他想:

我以前以为我懂政治——其实我懂的是 PR description——真正的政治是 Vikram 的 4 岁女儿在 SFO 抱着妈妈不肯走——是我招不到能接 Vikram 的工程师——是我们 v2.0 要砍 features—是 NextStream 估值要降——是硅谷整个 AI 生态在被慢慢勒紧。

我不能说。

但我懂了。

---

3 月 22 日凌晨 1:14——Kevin 加班到办公室空——他回家路上停在 Castro Street——打开 X (前 Twitter)——他写了一条 tweet——

> "Diversity wasn't just nice-to-have. It was load-bearing."

他停了 3 分钟——盯着发送按钮。

他没发——他删了——他锁屏——开车回家。

他想:有些东西—我懂—但我不说—5 年后说—10 年后说—不知道—但今天不说。

## 2 · 加州 · Maria

2032 年 1 月 24 日 / Bakersfield / Maria Hernandez 家。

Maria 38 岁——Walmart 早班 + Amazon 仓库夜班——一年过去了——她瘦了 12 磅——但她还在——她的丈夫 David 仍然失业——给两个孩子接送——做晚饭。

那天晚上 / 13 岁的 Diego 做数学作业——他突然抬头——

"妈妈—你看—我的数学课本是 2021 年版的—封面已经裂了—第 47 页缺了。"

Maria 走过去看——蓝色封面 / California State Math Grade 7 / © 2021 / 边缘磨损得像旧报纸 / 第 47 页缺角。

Maria 心里咯噔一下——但她笑着说："Diego—书没事—你能学就行—用 Google 找缺的页面。"

Diego："学校为什么不发新书。"

Maria："妈妈不知道—下周问校长。"

---

第二天 Maria 去学校——校长 Mr. Henderson (50 多岁 / 灰头发 / 西裔美国人 / 在 Bakersfield 做了 22 年公立学校管理):

Maria:"Henderson 先生—Diego 拿的数学书是 2021 年的—很多孩子拿的都是旧书—为什么不换。"

Henderson 苦笑:"Mrs Hernandez—我们 2025 年之后没换过教科书—因为 California State Education Budget 每年都被砍—2025 年砍 8% / 2026 年砍 12% / 2027 年砍 14% / 2028 年砍 11% / 2029 年砍 18% / 2030 年砍 15% / 2031 年砍 22% / 这个学期我们砍了 19%—我们能保证老师工资 / 校车油钱 / 暖气—但教科书 / 实验器材 / 体育用品 / 美术课 —— 都没钱。"

Maria:"为什么砍。"

Henderson:"州政府没钱—因为联邦给加州的教育拨款下降—因为联邦预算优先国防 + 国债利息—剩下给教育的不到 2%—州政府只能从自己税收里挤—但州税本来就紧—就这样。"

Maria 听到几个词:"国防—国债利息"—她不太懂—但她记住了。

她出来——回家——给 Diego 在 eBay 上买了一本 2024 版二手 California Math Grade 7—12 刀——她付了——书 4 天后到。

---

那个周末——Maria 在 Walmart 休息室——拿出手机——打开 Sarah Goldberg 的 Substack——这是她从 Ch 8 开始一直在读的——她不评论 / 不订阅付费 / 但每周读 1-2 篇。

新文章—标题:**"美国预算的几何形状:60% 国防 / 25% 债务利息 / 12% 其他 / 教育不到 1%"**

Maria 点开。

Sarah 写:

> "联邦预算 2031 年总额 $7.2 万亿——其中:
> - **国防(包括 Veterans + 国土安全 + 太空军 + 情报)**:$4.3 万亿（60%）
> - **债务利息**:$1.8 万亿（25%——比 2024 年翻倍）
> - **社保和医保**(已经在'非可支配预算'——总值 $5.1 万亿不在这 $7.2 万亿里)
> - **其他可支配项目**(教育 / 交通 / 住房 / 科研 / 环境):$1.1 万亿（15%）
> - **教育部联邦拨款**:$700 亿（不到 1%）"
>
> "美国对外债务 $42 万亿——主要外债持有者:
> - 中国持有 $1.4 万亿
> - 日本持有 $1.1 万亿
> - 英国 $750B / 比利时 $440B / 加拿大 $410B
> - 其他国家合计 $1.8 万亿
> - 美国国内（含联储 / 养老金 / 个人）持有约 $36 万亿"
>
> "我们每年付 $1.8 万亿利息——主要付给国债持有者——包括外国央行。**我们正在向我们被告知是敌人的国家付利息。被告知是敌人的国家正在买我们的债——因为如果他们停止买—美元跌—他们也跌—互为人质。**"
>
> "Diego 数学课本 2021 版的真正原因不是'加州州政府不重视教育'——是联邦预算结构性挤压——挤压的根本原因是 30 年累积的债务利息+持续上升的国防开支。EO-31-12 砍 H-1B 表面上是为了'美国工人优先'—但它砍的是硅谷生产能力—硅谷生产能力下降意味着美国未来 GDP 增长放缓—GDP 增长放缓意味着税收基数减小—税收基数减小意味着债务问题更严重——这是一个正反馈循环——我们走在它里面——而我们告诉自己我们在'保护美国'。"

Maria 读完——她不懂"正反馈循环"是什么——但她懂"Diego 的数学书 2021 版"。

她想:

Sarah 这个女人讲的东西—我大部分听不懂—但她说我家孩子的数学书—说对了—2021 版是真的—缺页是真的—我花 12 刀买二手是真的—Sarah 把这个连到联邦预算—连到国债—连到中国买债—我不知道这些是不是真的—但 Sarah 说的"Diego 数学书"那部分是真的—也许其他部分也是真的。

她想:

我以前以为我累是因为我个人不够努力—因为 David 不够积极—因为我们家不够会理财—但 Sarah 说这是结构性的—structural—我学过这个英文词—我不太懂—但好像意思是"不是你的错—是大环境"—我不知道这是不是借口—但我知道—Diego 的数学书不是 David 的错—也不是我的错。

她锁屏——回去打卡——下班路上接 Diego 放学——

Diego 在车里突然问:"妈—我们到底欠谁的钱。"

Maria:"什么。"

Diego:"今天历史课老师说—美国欠很多钱—我问老师欠谁—老师说—'问你妈'。"

Maria 在红灯前停车——她看着前面—她想了 3 秒。

她说:"Diego—妈妈也不全懂—但我们好像欠很多人—中国 / 日本 / 自己人 / 都欠—一共 42 万亿。"

Diego:"42 万亿 dollars?"

Maria:"是。"

Diego:"那我们怎么还。"

Maria:"妈妈不知道。"

Diego:"那我们还的起吗。"

Maria 没回答。

红灯变绿—她开车—Diego 在副驾位上看窗外。

Maria 想:

13 岁 / 他已经在问我"我们还的起吗"。

我希望他不需要在 13 岁问这个问题。

但他在问—因为他的数学书是 2021 版—因为他的学校砍了美术课—因为他爸爸失业 16 个月—因为他妈妈做两份工作—因为美国 30 年累积了 $42 万亿的债—因为我们告诉自己中国是敌人—但我们每年向中国付利息——

她没说出口。

她开车——Diego 在听 podcast——Maria 在握方向盘——天色黑——Bakersfield 的路灯一盏一盏经过。

## 3 · 北京清华 · 李慧珍

2032 年 3 月 18 日 / 北京 / 清华大学东主楼 / 计算机系办公室。

李慧珍 22 岁——大三下学期——选导师面试——她约了 3 位:

- 周一:汪正国教授（NLP 方向 / 60 岁 / 院士级 / 名声响 / 但学生反馈"非常严")
- 周三:刘斌教授（强化学习方向 / 42 岁 / 工业界回学界 / 之前在百度 / Smart 但也忙)
- **周五:王伟立教授（AI 安全方向 / 47 岁 / MIT CSAIL 8 年回国 / 2030 年 AFFSRA 第 9 条受害者 / 新加入清华一年半)**

李慧珍最期待周五。

她是从 Ch 8 那个 paper（"防止数据投毒"）之后开始关注王教授的——王教授在清华内部讲座做过一次 talk —— 题目"等离子体不稳定性的 AI 实时控制"——李慧珍去听过—她不懂物理—但她懂 AI 部分—她当时记下了王教授的一句话:"AI 安全在工程领域的最大挑战不是模型 robustness—是训练数据的物理一致性—训练数据如果被精确投毒—模型会在生产环境里精确失败—没有人能查出来。"

这句话和李慧珍 Ch 8 的 paper 主题完全契合。

她约了周五 3:00pm。

---

3 月 18 日 / 周五 / 14:55——李慧珍敲门。

王教授办公室——清华东主楼 4 楼——10 平米 / 满墙书 / 一张老木桌 / 三把椅子 / 桌上一台 ThinkPad / 两个咖啡杯 / 一盒美国饼干 (Pepperidge Farm Milano—显然从 MIT 时期带回来还没吃完)。

王教授 47 岁 / 偏瘦 / 灰头发 / 戴金属框眼镜 / 西装但不打领带 / 笑起来眼角有皱纹 / 说话语速比中国教授慢 (8 年 MIT 习惯了讲英语)。

王伟立:"李慧珍同学—请坐—想喝什么—咖啡—茶。"

李慧珍:"茶—谢谢王老师。"

王伟立倒了茶——他拉过一把椅子——

"我看了你 Ch 8 那个 paper—和 Lisa Chen 合作的—'防止数据投毒'—很扎实—工程方向也清晰—你想做什么。"

李慧珍:"我想做 AI 安全—但我想做工程 AI 安全—不是理论的—是跟物理系统挂钩的—比如您讲座里说的聚变反应堆控制—那种系统如果 AI 出错—不是模型预测错—是物理失败—等离子体崩塌 / 反应堆停—这种安全是不一样的。"

王伟立点头—他笑了一下:

"小李—你说的这个方向—在中国国内做的人不多—因为它要求你既懂 AI / 也要懂物理系统 / 也要懂工程 / 大部分 AI 学生只懂 AI—大部分聚变学生只懂物理—中间人很少。"

李慧珍:"我可以学。"

王伟立:"你愿意去合肥？"

李慧珍:"合肥？"

王伟立:"中科院等离子体物理研究所 / 合肥 / EAST 装置在那—我现在是兼职研究员—每月去 1 周—我的博士生大部分都在合肥呆 6-12 个月—因为 AI 控制的训练数据来自实际反应堆的运行—不能在北京做—得在那儿。"

李慧珍:"我愿意。"

王伟立看她—5 秒——他点头。

"好—我说说我想给你做的方向—你听—不喜欢可以走—不强迫。"

---

王伟立打开 ThinkPad——投影到墙上一个 PPT——

"聚变反应堆 AI 控制—简单说:

- 等离子体在 1 亿度温度运行 / 由强磁场约束 / 不能碰反应器内壁 / 否则反应停
- 等离子体不稳定性 (instabilities) 每秒可能发生几十次 / 必须毫秒级响应
- 传统 PID 控制器跟不上—因为不稳定性是非线性 / 多模态 / 有时混沌
- AI / RL 控制器可以处理—但要训练数据
- 训练数据来自历史等离子体放电记录—我们 EAST 装置 17 年累积了几百万次放电数据—中国唯一这么大的 dataset 在合肥
- 我的方法—在 MIT 8 年开发的—用 transformer 架构做等离子体状态预测+RL 做磁场调整决策—在 EAST 试运行了 14 个月—平均放电时长从 400 秒提升到 1500 秒—国际领先

李慧珍:"WOW。"

王伟立:"但—问题来了—

如果我们的训练数据被投毒—比如有人在某次放电记录里悄悄改了 0.1% 的磁场读数—模型学了这个错的数据—生产环境部署后—在某个特定温度+磁场+电流组合下—模型会发出错误磁场调整命令—等离子体撞墙—反应堆停—严重的话装置损坏。

这种攻击在传统 cybersecurity 框架下查不出—因为没有恶意代码—没有 backdoor—只是数据本身被精确调整—模型行为看起来正常—直到某个特定触发条件。

这就是你 Ch 8 paper 讲的'数据投毒'—但应用到聚变这种 critical infrastructure 上—风险是真实的物理灾难。

你的题目—我想给你的—是'聚变反应堆训练数据完整性的安全防护'—具体方法你定—我给你支持—第一年在清华学基础+物理—第二年起在合肥蹲点—4 年博士。"

李慧珍听完——她心跳加快——她知道这是一个一辈子的方向——她说:

"王老师—我接。"

王伟立笑了——他从抽屉拿出一份 paper——

"这是我 MIT 时期的最后一篇 paper—2030 年提交的—被驱逐前没发表—我把它带回中国—现在我们准备投 IEEE Transactions on Plasma Science—第一作者是我—我希望加你做第二作者—因为我看了你 Ch 8 那个 paper—你有这个能力。"

## 作者笔记

**为什么本章 5 个民众 POV + 1 主角线 = 维度章 ★。**

本章是全书第一个"真正的多线维度章"——5 个民众 + 周哲 = 5 个国家不同位置的不同年龄不同行业的人物，在同一时段（2032.1-5）做着完全不同的事——但所有事最终汇集成一个结构：**科技分水岭已经发生**。

科技分水岭不是某一天的事件——是这 3 年累积的：
- EO-31-12 砍 H-1B（2031.11）
- AFFSRA 第 9 条驱逐外籍研究员（2030 起）
- 王伟立这种"清除受害者"带回的技术 cluster
- 张大伟这种工厂的供应链国产化
- Tom Maria 这种民众的财政被挤压
- 周哲在中南海第一次系统看到 4 维度并列

5 条线无关——其实是同一件事——这种"看似无关其实同一"是本章的叙事美学——也是 G2 共识真正的物质基础（虽然此时 G2 共识还不存在 / 周哲也没有词形容这种结构）。

**关于美债叙事。**

美债是中美关系最深的物质纽带 / 也是被公开叙事最隐藏的纽带。本章用了三个层次铺开：

1. **民众层面 (Maria + Tom)**：Maria 通过 Diego 数学书 + Sarah Substack 第一次接触"债务利息 / 国防开支"概念；Tom 通过 H&R Block + Barbara 第一次具体算出"$144 一年到中国 / 我对抗中国 = 中国买债维持的"——这两条民众线让美债从抽象数字变成具体生活经验
2. **主角层面 (周哲)**：李副主席办公室对话 / 周哲解构"双向人质 / 互相不能真断 / 这是一种共同框架 / 但我没有词形容这个框架"——这是 G2 共识在金融维度的萌芽认知
3. **结构层面 (作者笔记)**：美国对抗中国 = 中国买债维持的财政基础——这种结构性悖论是后续章节（Ch 13 6 年准备 / Ch 18 叙事的诞生 / Ch 22 经济的重塑）的物质前提——本章铺垫到位 / 后续才能展开

**关于可控聚变叙事。**

聚变是中美技术分叉最锐利的物质化身——本章用了三个层次铺开：

1. **个人层面 (王伟立 + 李慧珍)**：MIT 8 年的"清除受害者"带回技术 cluster / 22 岁清华本科生选 AI 安全方向 / 与聚变挂钩
2. **工程层面 (张大伟)**：浙江工厂为合肥 EAST 做高纯度钨偏滤器 / 国产化供应链的具体物质化
3. **战略层面 (周哲简报 C)**：EAST 1500 秒 / CFETR 提前 18 个月 / NIF 放缓 / SPARC 推迟 / ITER 推迟 / 嫦娥-9 氦-3 提取——五维度对比 / 中国整体引领 / 美国被自身政策削弱

聚变也是与航天 (Ch 7 嫦娥村) + AI (Ch 8 李慧珍 paper) + 月球氦-3 (Ch 7 + Ch 8 + Ch 10) 形成的"中国技术 cluster"的核心节点——本章把这些点串起来——形成一个清晰的中国 2030s 技术战略图谱。

**关于"清除外国影响 = 自我清除"——AFFSRA 真正的物质代价。**

王伟立 = MIT 8 年聚变 AI 控制经验 + 训练 pipeline + 代码——全部带回中国——

**关于 Kevin 不能说 / Tom 不能说 / 周哲不能说——美国 + 中国共同的沉默结构。**

3 个角色 + 3 个国家不同位置——都在持有"两种真相"——都不能说出口——

- Kevin 私下懂 EO-31-12 砍硅谷生产能力 / 但 NextStream 拿 DARPA 合同 / 不能说

- 周哲私下懂"对抗 + 依存同时存在" / 但李 30 年经验 / 不能说

这是 2032 年中美关系真实的"沉默结构"——所有最了解真相的人都最沉默——所有相信表面叙事的人最不知道——这种结构不是阴谋——是物质环境对人的训练——所有理性人在这种环境下都会选沉默——因为说出来 = 失业 / 失友 / 失信任 / 失自由——而沉默 = 活——

5 年后 / 10 年后会不会有人能说出来——本章不解决这个问题——但本章把"沉默结构"具象化——让读者看见。
