# 相位转移装甲：盾的物理学

> 21 世纪后半叶最重要的防御技术。
> 不是装甲钢板，不是反应装甲。
> 而是用聚变能源在装甲板之间制造**相位错位场**——
> 让攻击能量在多块板之间分散、转移、消耗。
>
> 它**不能小型化**（必须连续大量供能 + 多块板分布）。
> 它由中国主导制造（"盾矛分工"中的"盾"）。
> 它装在装甲卫星、月球工业关键节点、装甲潜艇上。
>
> **它让 G2 体系在物质层面坚不可摧——直到汇聚日。**

## 一、物理原理

### 经典装甲的限制

20-21 世纪初的装甲技术:

- **物理装甲**（钢板、复合装甲）：靠厚度阻挡，被高速动能或高能量穿透
- **反应装甲**：靠爆炸抵消攻击，但每块装甲只能防一次
- **主动防御系统**：用拦截弹拦截来袭——但被多发饱和攻击就失效

进入聚变时代后，攻击武器变得极其强大:

- 千兆焦定向能武器（激光、粒子束）
- 高速电磁推进的弹丸（10+ km/s）
- 反卫星动能武器
- 等离子束

**没有任何被动装甲能挡住这些。**

### 相位转移装甲的解决方案

PSA（Phase Shift Armor）用一种完全不同的思路:
**不挡——而是分散。**

具体机制:

1. 装甲是由多块（典型 8-32 块）"主装甲板"组成
2. 每块板之间用聚变能源维持一个**相位错位场**
3. 当攻击命中其中一块时，能量被快速分散到所有板
4. 每块板分担总能量的 1/N，可以承受
5. 攻击点的板可能损坏，但整体结构保持

**关键：这需要持续的能量供应。**
没有能量 → 没有相位场 → 装甲变成普通钢板。

### 为什么不能小型化

PSA 的工作原理决定了它**不能装在单个士兵身上**:

**1. 能量需求**

- 维持相位场需要每块板每秒消耗几十千瓦
- 8 块板 = 约 200-500 千瓦持续功率
- 这相当于**整栋小楼的电力**
- 单兵根本背不动这么多能量

**2. 空间需求**

- 板间距至少 1-3 米才能形成有效相位场
- 单兵装甲只有几厘米空间

**3. 冷却需求**

- 相位场会产生大量废热
- 需要主动冷却系统，不能藏在身上

所以 PSA **天然只能装在大型平台上**:

- 卫星
- 大型车辆（主战坦克级，最小尺寸是装甲车辆群）
- 工业基地
- 海上平台
- 潜艇都市
- 月球基地

详见 [sustainable-war.md](./sustainable-war.md) 中关于林安然父亲死亡的描写——
萨赫勒战争中那个"先进单兵护甲"的错误描述被纠正后，
读者意识到：**单兵在 PSA 时代仍然是脆弱的。**
而装甲车辆（8 辆为一组的相位车辆群）才能形成有效防护。

## 四、政治经济学：为什么是中国主导

### 制造能力

PSA 制造需要:

- 高纯度超导磁体（中国主导）
- 月球氦三的辅助冷却（中国主导）
- 大规模工业生产（中国主导）
- 精密装配（中国 + 韩国 + 日本，但韩日为中国代工）

到 2070s，全球 PSA 制造的:

- 中国：约 70-80%
- 美国：约 12%（主要是关键算法 + 部分高级合金）
- 其他：约 10%

### 中美的"盾矛分工"

```
中国（盾的制造者）：
  - 相位转移装甲（多代版本）
  - 大型工业生产能力
  - 防御类无人系统
  - 反介入/区域拒止技术

美国（矛的制造者）：
  - 定向能武器（激光、粒子束）
  - 高精度打击系统
  - 反卫星武器
```

**为什么这样分工？**

- 中国有大型工业、月球氦三供应链、规模生产优势
- 美国有定向能武器的电子学优势、高精度打击系统、空间发射能力
- 双方互补，**没有一方能独立完成完整军事链**
- 这就锁定了双方对彼此的依赖

如果美国突然能独立做盾——它就不再需要中国
如果中国突然能独立做矛——它就不再需要美国
**所以双方都"故意"不全面发展。**

### 案例：相位转移材料的"日本起源"——美国出卖盟友

PSA 的早期发明，**不是中美的成果**。
**是日本的。**
**而日本的发明，被美国出卖给了中美拉格朗日共识。**

这是 21 世纪后半叶最精巧的"盟友交易"案例之一。

#### 真实起源（2030s-2046）：本来是抗震材料

故事的开始与防御无关——**与地震有关**。

2030 年代日本面对一个紧迫的工程问题:

- 富士山 + 关东直下型地震的双重风险
- 现有"减震建筑"技术不足以应对 8.5 级以上地震
- 日本工程界投入巨资研发"动态能量分散材料"

研发分两路:

- **理论与设计**：日本（东京大学 + 京都大学 + 东芝研究院）
- **材料工艺与生产**：韩国（三星先进材料 + 现代综合）

为什么这样分工？

- 日本擅长基础物理研究和精密设计
- 韩国擅长大规模生产 + 半导体级工艺
- 这是 21 世纪初东亚分工的标准模式

到 2046 年，日本-韩国联合团队完成了一项突破:
**"动态相位场建筑材料"**（Dynamic Phase Field Construction Material，DPF-CM）

这是 PSA 的**真正前身**。
理论原理与后来的 PSA 完全相同——
**通过相位场让能量在多块板之间分散**。

只是当时的应用场景是地震，不是武器攻击。

公开论文:

- 日本团队 2046 年 8 月在《Nature Materials》发表
- 论文标题：*Phase-coupled Field Dispersion in Multi-panel Composite Structures: Earthquake Engineering Applications*
- 第一作者：田中健太（Tanaka Kenta），东京大学应用物理系，38 岁
- 公开称为"对地震防御的革命性突破"

**论文一经发表，三方高层立即注意到。**

#### 三方都看穿了

但他们看到的**不是"地震防御"**——
他们看到的是**"军事应用潜力"**。

**日本高层（首相办公室 + 防卫省）：**

- 立即意识到这是"21 世纪最重要的军事材料"
- 内部讨论："如果我们独自开发军事用途，我们能成为军事强国"
- **但日本受《和平宪法》限制**
- 日本必须"分享给盟友"——按理这意味着分享给美国

**美国高层（国防部 + 国家安全委员会）：**

- 同样意识到军事应用潜力
- 内部讨论："这是我们等了 30 年的装甲技术基础"
- 美国希望**独占**这项技术

**中国高层（解放军 + 中科院）：**

- 同样意识到
- 但中国知道日本会"按规则"分享给美国
- 所以中国必须**通过其他方式**获得

三方都意识到这是一项**改变世界军事平衡的技术**。
**但只有日本——真正的发明者——不能完全控制自己的发明。**

#### 为什么中国能主导 PSA 生产：当时的物理与工业现实

到这里有一个关键问题需要回答:
**为什么 PSA 最终是中国主导生产，而不是美国？**

这不是偶然——是 2047 年那次交易时，**双方都已经知道的物理与工业现实**。
而正是这些现实，让美国在密会上**理性地认为**这是一笔好买卖。

##### 现实一：中国具备唯一的批量化生产能力

PSA 装甲的核心需求是**批量化生产**:

- 单一装甲卫星需要 8-32 块板
- 全球部署需要数千颗卫星
- 加上军事车辆、装甲潜艇、月球基地——
- 总产量需求：每年数十万块装甲板

只有中国具备这种规模的精密制造能力:

- 中国制造业占全球聚变相关精密设备的 65%+
- 中国半导体级精密制造产能是美国的 5 倍
- 中国"超导磁体 + 复合材料 + 高纯度合金"完整产业链
- 美国在批量化方面已经无法竞争

**美国在 2047 年时已经清楚：自己根本没法量产 PSA。**

##### 现实二：月壤稀土的开发与精炼完全在中国手里

**这是最关键的事实。**

PSA 板的核心材料需要:

- 月壤稀土（特殊稀土元素 + 月壤特有的同位素组合）
- 高纯度提炼到 99.9999% 以上
- 大规模工艺级提取

到 2047 年时，月壤产业链的全球分布:

```
月壤采集（2047）：
  中国（嫦娥工坊）：85%
  美国（晨曦站）：12%
  其他：3%

月壤精炼（2047）：
  中国（地球+月轨）：92%
  美国（地球）：8%
  其他：0%

月壤稀土纯化（2047）：
  中国：完全垄断
  美国：依赖中国进口
```

**没有中国月壤精炼能力，PSA 板根本造不出来。**

美国在 2047 年的内部评估写道:

> "即使我们独占 PSA 技术——
> 没有中国月壤产业链，
> 我们也无法量产。
> 与其'独占一项无法实现的技术'，
> 不如'换取中国的实质让步'。"

##### 现实三：中国是当时最强大的生产中心

到 2046-2047 年:

- 中国 GDP 已经超过美国（按购买力平价）
- 中国制造业占全球 38%
- 中国精密制造产能是美国的 5-6 倍
- 中国的"军民融合"产业链让它能快速扩展到任何工业领域

任何需要"大规模复杂工业生产"的项目，
**中国都比美国更适合做主导生产方**。

这不是政治选择——是物质现实。

##### 现实四：美国看到的"致命问题"——能量供应

但即使中国具备生产能力，美国为什么愿意"卖"？

**因为美国当时认为 PSA 有一个无法解决的问题：能量供应。**

具体的物理矛盾:

```
PSA 的能量需求 vs 当时（2047）的聚变堆:

  PSA 单板能量需求：100-500 千瓦持续
  PSA 装甲卫星总需求：约 1-5 兆瓦

  当时（2047）可用的聚变堆：
    最小型：50 兆瓦（占地约 100 平方米）
    中型：500 兆瓦（占地约 1000 平方米）

  问题：
    - 装甲卫星只能装下"小到不可能的反应堆"
    - 反应堆缩小到这种程度，技术上无法实现
    - 没有小型聚变堆，PSA 装甲卫星无法供电
    - 所以 PSA 卫星在 2047 年看起来根本"无法实战部署"
```

更深的问题:

- 想要 PSA 真正用起来，需要**聚变小型化**
- 而聚变小型化在当时是 G2 共同的禁忌（这一禁忌后来在 2068 年正式成文）
