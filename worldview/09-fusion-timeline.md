# 可控核聚变时间线：从突破到禁忌

> 这本小说的所有政治都建立在一件物质事实之上：
> **可控核聚变在 2032 年实现商业化。**
> 但这件事不是一次性的"完成"——
> 它是一个跨越 100 年的复杂演进过程，
> 涉及多种聚变路径、多个工业代际、
> 以及一个最关键的禁忌：**不能小型化**。

---

## 一、聚变物理速查

聚变的核心：让两个轻原子核克服库仑斥力融合，释放能量。
21 世纪后半叶有三条主要"路径"，每条路径有不同的难度和应用场景:

```
D-T （氘-氚）：
  反应：²H + ³H → ⁴He + n + 17.6 MeV
  难度：相对最低（首先达成商业化）
  问题：氚 ³H 半衰期 12 年，必须从锂工业制造
        中子辐射强烈，结构材料快速老化
  现状：2032 年商业化，主导整个 21 世纪后半叶

D-³He （氘-氦三）：
  反应：²H + ³He → ⁴He + ¹H + 18.3 MeV
  难度：中等（需要更高温度）
  优势：辐射极少（"清洁"聚变）
  问题：地球缺氦三，必须从月球氦三沉积获取
  现状：2055 年首座商业堆运行（在月轨实验室）

p-¹¹B （质子-硼十一）：
  反应：¹H + ¹¹B → 3 ⁴He + 8.7 MeV
  难度：极高（点火温度比 D-T 高一个数量级）
  优势：完全无中子（最理想的能源）
  状态：2086 年在普罗米修斯基地接近突破
        但被拉格朗日共识严密管控
        2125 年装甲潜艇宣布实质突破
```

**每一种聚变路径的"小型化可行性"是不同的:**

- **D-T**：理论上可以小型化到桌面级，但氚供应问题让小型化经济上无意义（每个家庭都需要专人管理氚）
- **D-³He**：可以小型化，但氦三供应被拉格朗日共识垄断
- **p-¹¹B**：硼遍地都是，**这是真正的"能源民主化威胁"**——这就是为什么拉格朗日共识最害怕它

## 二、时间线

### 阶段一：奠基（2025-2032）

- 2025-2027：ITER 接近 Q=10 突破，但仍不商业化
- 2026-2028：Helion (美国) 和 中科院 (中国) 同步推进 SPARC 路线
- 2027-2028：嫦娥-7 月球南极探测，确认氦三储量
- 2030：第一个"商业"小型 SPARC 点火（仅净输出 0.3 MW，仍非工业级）
- 2031：ITER 首次氘氚等离子体实验（学术里程碑）

### 阶段二：突破（2032-2040）

- **2032.11.8：Helion 在华盛顿州的聚变堆首次商业并网**
  - 微软的数据中心吃下第一份聚变电力
  - 输出功率 50 MW
  - 这一天石油美元判决书签下（详见 [04-old-america-death.md](./04-old-america-death.md)）
- 2033：中国 CFETR 测试堆达到 Q>30
- 2033：第二座商业聚变堆并网（上海）
- 2034：法国、英国、日本、韩国跟进
- 2036：全球聚变堆达到 12 座
- 2037：中国宣布"全国聚变发电"路线图
- 2040：全球聚变堆达到 25 座

**阶段二的政治意义：**

- 中国掌握 55% 制造能力
- 美国"聚变美元"梦碎（详见 [04-old-america-death.md](./04-old-america-death.md) 第四节）
- 2035 美元危机 + 中国救援

### 阶段三：扩展（2040-2055）

- 2042：第一座大型质量投射器开建（青藏高原）
- 2042：月轨第一座微重力聚变研发实验室
- 2046：中国"嫦娥工坊"永久工业基地建立
- **2049：全球第二代 D-³He 聚变堆测试成功（在月轨实验室）**
- 2050：全球聚变堆达到 50 座
- **2055：第一座完整 D-³He 商业堆运行**

**阶段三的政治意义：**

- D-³He 商业化让中国在聚变上的领先地位更加巩固（因为 He-3 来自中国主导的月球工业）
- "聚变美元"概念被永久埋葬
- 全球能源中继网络开始建设（详见 [12-energy-relay-satellites.md](./12-energy-relay-satellites.md)）

### 阶段四：禁忌成文（2055-2080）

- 2056：无中子聚变（p-¹¹B）研究的关键论文发表（"独立学者"）
- 2065：全球能源中继网络达到峰值规模
- 2066：地下大型研究设施事故频发（辐射污染让小型化研究在地下不可行）
- 2067：拉格朗日共识危机意识形成（中美最高层在拉格朗日宫殿讨论）
- **2068：《禁止聚变小型化国际公约》签署**
  - 公开理由：防止聚变武器化
  - 实际理由：维持拉格朗日共识垄断
  - 同时秘密决定："必须有外包研究方案"
- 2070：第一次明确的"深蓝项目"讨论（拉格朗日共识最高层秘密会议）
- 2078：月球研究公约签署
- 2080：普罗米修斯月球研究基地开始建造

### 阶段五：分裂（2080-2110）

- 2080：深蓝项目正式启动（绝密）——装甲潜艇都市秘密研究开始
- **2086：普罗米修斯基地"无中子聚变"研究接近突破**
- 2089：普罗米修斯基地的"猜疑链"开始
- **2093：普罗米修斯基地"事故"——重大悲剧**
  - 公开：研究基地遭遇严重事故
  - 实际：拉格朗日共识某派系发动奇袭，被反制
  - 数千人死亡或失踪
- 2095：沉默公约达成（绝密）——拉格朗日共识同意装甲潜艇方案
- 2096-2099：装甲潜艇都市开始建造
- 2105：第一艘潜艇都市进入哈达尔层
- 2110：12 艘潜艇都市全部部署

### 阶段六：突破（2110-2125）

- **2117：装甲潜艇研究在四个领域接近突破**
  - 自我复制：约 70%
  - p-¹¹B：约 40%
  - 直接推进：约 60%
  - 大规模制造：约 30%
- 2120：拉格朗日共识最高层察觉到潜艇研究进展
- 2121：拉格朗日共识决定在"未来某时"打击潜艇
- 2122：潜艇都市的研究接近"临界点"
- 2123：最终决定：18 个月内打击
- **2125：汇聚日——装甲潜艇宣布 p-¹¹B 桌面级聚变实质突破**

## 三、核心概念：为什么"小型化"是禁忌

简言之：

- 大型聚变 = 集中能源 = 拉格朗日共识可以收过路费 = G2 共谋成立
- 小型聚变 = 分布式能源 = 每家有自己的太阳 = G2 共谋瓦解

所以中美的最高共识是：
**"大型聚变可以，小型聚变绝对不行。"**

详细分析见 [08-fusion-suppression.md](./08-fusion-suppression.md)。

## 四、关键技术细节（写作脚手架）

### D-T 反应堆（2030s-2050s 主流）

- **体积**：典型商业堆约 100 米直径，30 米高
- **输出**：50-500 MW
- **关键技术**：
  - 高温超导磁体（限制等离子体）
  - 锂铍合金第一壁（吸收中子，制造氚）
  - 钨铜合金散热墙
- **制造商**：约 75% 中国（中科院 + 上海电气 + 几家国企）
- **寿命**：约 30 年（中子辐射让结构材料退化）

### D-³He 反应堆（2055+ 高端）

- **体积**：可以更小（约 50 米直径）
- **输出**：100-300 MW
- **优势**：辐射极少，材料寿命长
- **限制**：氦三供应（每年约 100 吨）
- **在哪里运行**：主要在月轨实验室和地球大型站点

### 月球氦三采集

- **月壤含量**：约 0.001-0.01 ppm
- **采集方式**：表层挖掘 + 加热到 700°C 释放
- **主要来源**：月球南极、Mare Imbrium 等富集区域
- **中国主导**
- 详见 [10-lunar-industry.md](./10-lunar-industry.md)

### 装甲潜艇都市的"秘密研究"

- **重点**：p-¹¹B 反应堆的桌面级化
- **方法**：三种路径并行
  - 激光惯性约束（小型化）
  - 场反构型（FRC）
  - Fusor 类型的优化
- **进展**：2120 年代接近突破
- 详见 [08-fusion-suppression.md](./08-fusion-suppression.md)

## 五、聚变与其他系统的连接

聚变不是独立的技术。
它是 G2 体系的"中央太阳"——
所有其他物理基础设施都围绕它建立:

```
聚变（09）作为中心 →
  ├── 月球氦三供应链（10）—— 提供 D-³He 燃料
  ├── 能源中继卫星网络（12）—— 分配集中聚变电力
  ├── 相位转移装甲（11）—— 保护聚变基础设施
  └── 装甲潜艇都市（08）—— 秘密研究小型化
```

每一个其他系统都依赖聚变。
没有聚变，整个 G2 物质架构不存在。
但**聚变小型化**——
会让这整个架构瞬间瓦解。

## 七、不同代际公众的"聚变叙事"

聚变在不同时代被讲述的方式不同。
这对小说的写作很重要:

**2030 年代（突破期）**：
"聚变是人类的救星！清洁能源时代来临！"
（媒体狂热，公众充满希望）

**2040-2050 年代（扩展期）**：
"聚变让一切变好。中国领先全球。"
（已成为常识，不再是新闻）

**2060-2080 年代（禁忌期）**：
"聚变让我们安全。但聚变武器化的风险必须避免。"
（公众接受"必须管控"叙事，不质疑为什么）

**2100 年代（成熟期）**：
"聚变是基础设施，像 20 世纪的电网一样。"
（已成日常，年轻人无法想象石油时代）

**2125 之后**：
"聚变本可以更早小型化的。是有人在阻止。"
（汇聚日揭露之后的反思）

每一代人对"聚变是什么"的理解都不同。
所以小说的不同时代场景需要用不同的"聚变话语"。
