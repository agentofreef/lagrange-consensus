## 核心命题（一页摘要）

### 物质基础

2032 年 11 月 8 日，Helion 商业聚变并网。
石油美元的死亡判决书在那一夜被签下。
但聚变本身没有自动解放人类——
关键在于聚变是**集中的**还是**分布的**。

### 政治架构

中美形成了"拉格朗日共识共治"。
表面持续对抗，实际共同管理世界。
2035 年中国 2.4 万亿美元救美元，
完成了人类历史上最值钱的一笔投资——
不是控制了美国，而是与美国精英建立了**清醒的相互信任**。

### 关键机密

要让拉格朗日共识持续盈利，
聚变必须**保持集中**。
所以中美在表面竞赛之下，
达成了不可言说的最高共识：
**"大型聚变可以，小型聚变绝对不行。"**
这是 G2 体系最核心的物质秘密。

### 反抗的来源

反抗不来自传统意义上的"对手"。
来自拉格朗日共识自己外包给装甲潜艇的研究队伍——
他们觉醒了。
来自月球工业的第二代——
月生代发现自己是被使用的。
两者在 2125 年的"汇聚日"合流。

## 写作守则（自用）

1. **不写阴谋叙事。** 这不是"邪恶秘密集团统治世界"。是结构性的、几代人共同维持的、不被任何单一意志主导的政治真实。
2. **不写道德判断。** 国家的"聪明"或"愚蠢"是结构性位置，不是人格评价。
3. **始终保持中美对称。** 不要把中国写成"邪恶崛起者"，也不要把美国写成"无辜受害者"。两者都是清醒的参与者。
4. **关键秘密是物质性的。** 不是阴谋，不是黑料，是聚变小型化的工程禁忌。
5. **反抗不来自国家。** 来自体系内部最不被信任的群体——海底研究员和月生代矿工。
6. **不写"觉醒民众"老套叙事。** 中美民众其实是 G2 体系的物质受益者；觉醒不会让他们反对体系，只会让他们陷入"清醒但选择继续参与"的复杂状态。真正的输家是第 3、第 4 层国家。
7. **对抗 > 合作。** 这本书最反直觉的命题：中美在"对抗状态"下获得的总利益，比"明面合作"还要多。对抗叙事是 G2 共治的防火墙——它让第三方国家保持恐惧、仆从国保持依附、国内民众保持动员。所以双方都不会真的合作，即使他们事实上已经在共治。
8. **拉格朗日共识成员是"好人"。** 不要写成邪恶反派。10-12 个核心决策者人品无可挑剔、生活极简朴（白粥咸菜鸡蛋 / 燕麦粥煎蛋咖啡）、家人以身作则、孩子从未获得特殊优待、对权力的渴望节制、始终考虑民众。**好人维持着伤害几十亿人的体系——因为他们相信这是"较小的恶"。** 这是这本书的核心问题：好人能不能做坏事？读者要无法真正恨他们，但要看清他们做的事的总效果。
9. **不使用"卡特尔"一词。** 这本书有三层国际治理结构：联合国（公知）/ GFSSC 聚变 OPEC（公开但少有人关注）/ 拉格朗日共识（绝密，只中美最高层 10-12 人知道）。**绝不使用"卡特尔"一词**——它太商业、太负面、太清晰。"拉格朗日共识"是事后历史学家给的名字，参与者自己很少命名它。
10. **多极世界是幻觉。** 所有非 G2 国家的领导和民众都相信自己生活在多极世界中。中美的"完美平衡"表演让所有盟友相信"只要再多做一点，我支持的那一方就能彻底赢"。**这种幻觉是 G2 收钱的关键机制**——盟友自愿"贴钱"，但其实早在 2036 年中美就秘密达成了共识。
11. **文明代差：中国政治 2000 年领先 + 西方技术 200 年领先（基于资本主义 Nash 均衡）。** G2 不是两个国家的合作，是两个文明的合体。"Mark Chen 模式" = 推恩令；"三层世界" = 中国朝廷三层；"黑调试" = 老子无为；"人情" = 儒家礼；"对抗 > 合作" = 孙子虚实；"盾矛分工" = 远交近攻。**所有"创新"在中国都有 2000 年传统对应**——是美方主动观察到中方策略的有效性后向中方提问、领悟的（不是中方"教训"美方）。最深的洞察：**这不是谁更聪明，不是种族优越，只是文明的"年龄"不同**——中国 5000 年文明在政治上极成熟，西方文明在近 200 年技术爆炸（资本主义+Nash 均衡让市场自我组织达到最优），两个文明各自走了不同的路，G2 让两者最强项合体。Davidson 金句："**我以为我们是大人，他们是孩子。原来我们都是孩子——只是在不同的课堂里。**"

12. **PSA 不是中美发明的——是日韩发明的。** 真实发明者：田中健太博士（日本东京大学），2046 年发明，**动机是防御地震**。中美情报系统几乎同时识别军事潜力，2047 年 1 月 8 分钟密会确定收购方案（70% 价格 + 10% 永久分成 + 30-50 年人情）。日本/韩国"卖了好价格"——但完全不知道自己卖的是什么；日本科技此后永久衰退。**这是 G2 第一次主动合谋的代价由"被合作的第三方"承担**——这种"对第三方的精确管理"是 G2 90 年间反复使用的模式。**写作时**：任何 2046 年之前的"PSA""主动装甲""相位转移"都是错的——那时候只有经典装甲。

13. **军工复合体被法律强约束（2055-2068 立法浪潮）。** 中美都不是"军工绑架政治"——反而是"政治阉割了军工"。美国：禁止任何形式的竞选资助（一分钱都不行）、关旋转门、强制公共服务投入；中国：禁止以"外部威胁"作为预算合理性论据、强制民用衍生、家庭利益申报严苛。**结果**：军费的 30-45% 实际流回民生（基础医疗、教育、城市更新）——**这是 2050s 中国 35 小时工作周和美国半公共医疗的主要物质基础**。**写作时**：不要写"军工绑架政府"老套叙事——21 世纪后半叶相反，**军方是被政治阉割的执行工具**。

14. **双方军方都"知道是在演戏"，且必须知道。** 中美军方最高 50-100 名将领都清楚"中美不会真的开战""敌人是预算工具"。**真心相信对方是敌人的高层会被逐渐边缘化**——不是清洗，是调任到地方军区/顾问职/培训中心，5-10 年后影响力自然消失。**晋升到最高决策层的，必然是"知道这是表演"的人**。这种"军方的清醒"反而是 G2 体系稳定性的关键——如果军方真的备战，G2 共治会崩溃。**写作时**：将军视角永远要带着这种"清醒的演员"色彩，绝不写"鹰派将军主战"老套桥段。

15. **盾与矛的真实目的是月球资源开采。** 这是整个体系最深的物质底色。**盾（PSA / 装甲卫星 / 装甲潜艇）**真实功能：抵御月震、微陨石、采矿事故、能源中继保护——**月球地表所有永久建筑标配 PSA**，地球军方只占全球 PSA 产能的 15-20%。**矛（定向能武器 / 质量投射器 / 等离子炬）**真实功能：月球矿物切割、运输、深层钻探——"武器化版本"只是改了瞄准系统。**军费的 60-70% 按真实物质流向是花在月球工业链条上的**，不是花在准备打仗。Robertson 部长金句："**我们把它叫做军费，是因为'军费'比'月球开采基础设施费'更容易让国会通过。**"**写作时**：永远记得"军事对抗是封皮，月球开采是内核"——任何"军事"场景都应该有月球工业的物质底色透出来。
