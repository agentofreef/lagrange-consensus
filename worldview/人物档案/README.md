# 人物档案

> 这个文件夹收录小说中关键人物、势力、事件的详细描述。
> 每个档案都是一个独立的文件，可以反复展开。
>
> 这些档案不是"小说里的人物"——而是
> **小说世界中可以发生的角色原型**。
> 写小说时，可以从这些档案中挑选合适的人物作为视角人物，
> 或者把多个档案的特征组合成一个虚构角色。

## 档案的格式

每个档案应包含：

1. **基本信息**：姓名、年龄、国籍、职位
2. **物理描述**：外貌、衣着、习惯
3. **背景**：成长经历、家庭、教育
4. **角色定位**：在 G2 体系中的位置
5. **关键时刻**：参与的重大历史事件
6. **性格细节**：让人物可信的小细节
7. **关系网络**：与其他角色的关系
8. **对主线剧情的意义**

---

## 使用说明

写小说时可以：

- **直接使用**某个档案作为人物原型
- **组合**多个档案的特征
- **修改**细节以适应具体情节
- **借用**关键场景作为戏剧化时刻

档案不是小说本身——
**它们是小说的"人物素材库"**。
